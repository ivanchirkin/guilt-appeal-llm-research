# Локальные скрипты

Все пути вычисляются относительно корня репозитория; абсолютные пути к авторскому компьютеру не нужны.

| Скрипт | Назначение |
|---|---|
| reproduce.py | Полная проверка, расчёт и построение диаграмм |
| validate_corpus.py | Реестр, SHA-256 источников и совпадение корпуса с DOCX/авторской заменой |
| validate_annotations.py | Текущая схема, точность цитат, уровни, порядок и выборка |
| calculate_metrics.py | GUILT, NAT человека и модели, FLD/FREQ, нормировка и сводные таблицы |
| build_summary.py | Обновление README и аналитического описания из итогового JSON |
| build_figures.py | 17 диаграмм, форматы PNG/SVG и PDF-сборники |
| validate_results.py | Согласованность источников, таблиц, JSON и происхождения диаграмм |
| study.py | Определения единиц, ввод-вывод и общие формулы |
| prepare_corpus.py | Первичная подготовка; отказывается перезаписывать существующий корпус |
| common.py | Парсер исходных документов и авторских замен |

API не вызываются. Скрипты не генерируют новые диалоги и не принимают лингвистические решения.
