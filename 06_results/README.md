# Результаты

Единый источник для всех диаграмм — [summary.json](summary.json).
Все расчёты относятся к D001–D024 и используют проверенные аннотации.

| Файл | Содержание |
|---|---|
| dialogue_metrics.csv | Четыре метрики по диалогам, обе оценки GUILT/NAT, объём и нормировка |
| group_summary.csv | Средние, медианы, минимумы и максимумы по четырём группам |
| g_code_distribution.csv | 360 строк диалог × код и 60 строк группа × код |
| category_summary.csv | Частоты и охват диалогов по категориям G01–G15 |
| level_summary.csv | Частоты и доли языковых уровней по группам |
| nat_distribution.csv | Распределения NAT человека и модели по группам и всей выборке |
| guilt_confusion.csv | TP, TN, FP, FN относительно человеческого эталона |
| summary.json | Все результаты, определения, условный сценарий и SHA-256 входов |
| validation_report.json | Результат технической проверки |
| figures/ | 17 диаграмм PNG/SVG и три PDF-сборника, две авторские иллюстрации статьи |
| analysis.md | Актуальное аналитическое описание |
| reports/history/ | Два ранее подготовленных DOCX-отчёта; исторические формулировки сохранены |

CSV: UTF-8 с BOM, запятая как разделитель, точка как десятичный знак.
Формулы и ограничения: [DATA_DICTIONARY.md](../DATA_DICTIONARY.md).
`reference_gated_sensitivity` — условное обнуление FLD/FREQ по человеческой метке;
оно не подменяет основной расчёт и не является новой лингвистической разметкой.
