# Воспроизведение результатов

Требуется Python 3.11. Для среды расчёта сохранён полный набор используемых зависимостей
в `requirements.lock.txt`; диапазоны прямых зависимостей — в `requirements.txt`.

```bash
python -m venv .venv
# Активируйте .venv средствами своей ОС
python -m pip install -r requirements.lock.txt
python 07_scripts/reproduce.py
```

Команда выполняет шесть регрессионных проверок научных правил подсчёта, проверку корпуса
и аннотаций, пересчёт таблиц и JSON, построение всех диаграмм и проверку происхождения
результатов. Расчёт не обращается к сетевым сервисам. Установка зависимостей требует
доступа к индексу пакетов либо заранее подготовленного локального набора пакетов.

Быстрая проверка уже сохранённых диаграмм:

```bash
python 07_scripts/reproduce.py --no-figures
```

Исходный корпус воспроизводится из четырёх DOCX, фиксированного seed и авторской
замены D040. `prepare_corpus.py` предназначен для отдельной пустой копии и отказывается
перезаписывать существующие материалы. Готовый корпус имеет стабильные ID.

Результаты воспроизводимы из сохранённых текстов, аннотаций и человеческих оценок.
Повторная генерация тех же диалогов веб-моделью не гарантируется: отсутствуют точные
версии, параметры и журналы запусков. Бинарный вид графиков может зависеть от среды
рендеринга; первичны числовые результаты и сохранённые данные.

`06_results/summary.json` фиксирует SHA-256 всех входов расчёта, а
`06_results/figures/manifest.json` связывает изображения с этим расчётом.
GitHub Actions запускает проверку после push/PR; публикация на GitHub — отдельный шаг.
