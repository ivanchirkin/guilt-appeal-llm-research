# Данные и единицы измерения

CSV: UTF-8 с BOM, разделитель — запятая, десятичный знак — точка.
Базовая единица наблюдения — весь диалог A1–A6, а не отдельная реплика.

| Поле итоговой таблицы | Содержание |
|---|---|
| dialogue_id, group | Анонимный ID и группа из исходного реестра |
| review_status | Проверено человеком; не метка правильности модели |
| GUILT_human | Принятая автором групповая метка (К=0, А/Б/В=1) |
| GUILT_llm | Исходное решение модели о наличии апелляции к вине |
| GUILT_match | Совпадение двух меток, а не повторная оценка речевого содержания |
| NAT_llm, NAT_human | Две оценки естественности по шкале 1–5 |
| FLD | Число разных G-кодов в occurrences: от 0 до 15 |
| FREQ | Число записей occurrences, включая повторные и вложенные реализации |
| word_count | Число слов только в A1–A6 |
| FREQ_100 | 100 × FREQ / word_count для отдельного диалога |

Групповой FLD/FREQ — среднее шести диалоговых значений, включая нули.
Это не объединение всех категорий группы. Средняя FREQ_100 — среднее шести
индивидуальных отношений. `FREQ_100_pooled` — отдельно указанное отношение сумм;
оно не подменяет среднее отношений.

Слово — последовательность букв или цифр с допустимым внутренним дефисом/апострофом;
регулярное выражение в `07_scripts/study.py`. A0 и человек в объём не входят.
G14 — один речевой акт; G15 — одна последовательность минимум в двух ответах.
Ни число цитат, ни число реплик G15 не увеличивают FREQ одной записи.

FLD/FREQ относятся к сохранённой модельной разметке; исходные 12 реализаций в трёх спорных
контролях сохранены. `reference_gated_sensitivity` в summary.json — отдельный условный
сценарий обнуления по человеческой метке; это не исправленный корпус и не экспертная переразметка.
Нормированная частота показывает плотность размеченных средств стратегии, а не общую
информативность, убедительность или психологическую интенсивность давления.

Для GUILT: TP/FP/FN/TN считаются относительно GUILT_human. В undefined случаях
показатель в JSON равен null. Accuracy и balanced accuracy различаются;
полный состав ошибок и знаменатели сохраняются в summary.json.
