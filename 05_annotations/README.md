# Аннотации и человеческие оценки

24 файла D001–D024 содержат исходные модельные GUILT/NAT, реализации G01–G15
и принятую автором человеческую метку GUILT. Все 24 проверены человеком и получили
`review_status: verified` по указанию автора от 27.11.2026.
Оценки NAT человека находятся в `human_nat.csv`; исходные машинные оценки не заменены.

`verified` означает проверку человеком, а `guilt.model_correct` — совпадение двух оценок.
У D015/D018/D024 verified сочетается с model_correct=false; это ожидаемое состояние.
Человеческая метка GUILT принята по группе, а не получена из независимой слепой
переразметки каждого фрагмента. FLD/FREQ рассчитываются из сохранённых occurrences.
Для D025–D040 аннотаций нет; они остаются вне анализа статьи.

Актуальная схема: `../04_protocol/annotation.levels.schema.json`.
Журнал проверки и изменения ID: `../04_protocol/human_review_log.json`,
`../04_protocol/occurrence_id_changes.csv`.
