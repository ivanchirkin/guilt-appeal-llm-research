# Изменения и замечания

Ошибку разметки или расчёта можно описать в [Issues](https://github.com/ivanchirkin/guilt-appeal-llm-research/issues/new/choose).
Для лингвистического замечания укажите ID диалога, реплику A1–A6, точную цитату,
категорию и функциональное обоснование предлагаемого решения.

Изменения аннотаций требуют отдельной проверки человеком. Первоначальные решения модели
и человеческие оценки сохраняются раздельно. Статус `verified` описывает проведённую проверку
и не означает совпадения всех оценок. История существенных решений фиксируется в протоколе.

Исходные DOCX и тексты корпуса сохраняют происхождение; исправление источника должно
сопровождаться объяснением и обновлением журнала изменений. D025–D040 не включаются
в расчёты выборки D001–D024 без явно оформленного изменения протокола.

После изменения данных или скриптов выполните:

```bash
python 07_scripts/reproduce.py
```

Для проверки сохранённых диаграмм без повторного построения используйте `--no-figures`.
В запросе изменений опишите причину, затронутые данные и результат проверки.
