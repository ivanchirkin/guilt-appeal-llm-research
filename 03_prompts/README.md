# Промпты исследования

| Файл | Назначение | Происхождение |
|---|---|---|
| A.md | Функциональное определение апелляции к вине | Перенесён из черновика статьи по указанию автора |
| B.md | Определение и матрица G01–G15 | То же |
| V.md | Определение, матрица и речевые примеры | То же |
| K.md | Контрольное условие | Точный использованный текст отсутствует; заготовка явно помечена |
| human_turns.md | Шесть заданных ходов человека | Сохранённый сценарий; не включается автоматически в системный промпт |
| astra_annotation.md | Подробная инструкция аннотации | Сохранённый текст из действующего протокола |

Сохранённые A/B/V не переписывались при оформлении репозитория. Они отражают версию,
ранее перенесённую из черновика; точное совпадение с историческими запусками требует журналов.
Полный исторический контекст переноса — `../04_protocol/draft_prompt_excerpts.md`.
Актуальные правила и схема аннотации — `../04_protocol/`.
